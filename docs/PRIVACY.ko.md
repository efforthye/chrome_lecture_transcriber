# 개인정보처리방침 — Lecture Transcriber

**한국어** · [English](PRIVACY.md)

_최종 수정일: 2026-10-16_

Lecture Transcriber(이하 "확장 프로그램")는 강의 영상을 텍스트 스크립트로 만들어 줍니다. 이 문서는 확장 프로그램이 어떤 데이터를 다루는지 설명합니다. 요약하면 **확장 프로그램은 자체 서버가 없고, 분석 도구로 데이터를 수집하지 않으며, 데이터를 판매하거나 공유하지 않습니다.** 저장되는 모든 것은 사용자의 브라우저에 남고, 오디오는 사용자가 고른 음성인식 서비스로만 전송됩니다.

## 다루는 데이터

| 데이터 | 목적 | 전송·저장 위치 |
|---|---|---|
| 사용자가 고른 **영상의 오디오** | 음성을 텍스트로 변환 | 사용자가 선택한 음성인식 API(**Groq** 또는 **OpenAI**)로, 사용자 본인의 API 키로 전송됩니다. 오디오는 영상을 제공하는 서버에서 직접 내려받으며 개발자에게는 전송되지 않습니다. |
| **API 키** | 음성인식 API 인증 | 기기의 `chrome.storage.local`에 저장됩니다. 선택한 서비스에만 인증 헤더로 전송되며 개발자에게는 전송되지 않습니다. |
| **스크립트, 강의 제목, 페이지 주소** | 결과 표시 및 내보내기 | 사용자가 삭제하거나 확장 프로그램을 제거할 때까지 기기의 `chrome.storage.local`에 저장됩니다. |
| **설정과 사용량 기록** (서비스, 언어, 내보내기 옵션, 보낸 오디오 양) | 설정 기억, 무료 한도 추정 | 기기의 `chrome.storage.local`에 저장됩니다. |
| **유튜브 자막** | 유튜브 영상의 스크립트 생성 | 탭에 열린 유튜브 페이지(및 브라우저 세션으로 접근하는 유튜브 자막 주소)에서 읽어 옵니다. 다른 곳으로 전송되지 않습니다. |
| **선택한 탭의 페이지 내용** | "강의 추가"를 누른 뒤 영상 원본 주소를 찾기 위한 용도로만 (`<video>` 요소, 네트워크 기록, 페이지 HTML) | 기기 안에서만 처리됩니다. 원본 주소와 목록에 보이는 페이지 제목·주소 외에는 저장하지 않습니다. |

확장 프로그램은 이름, 이메일, 방문 기록을 수집하지 않으며 광고·분석·프로파일링 목적으로 어떤 데이터도 수집하지 않습니다. 사용자가 직접 "+ 강의 추가"(또는 단축키, 우클릭 메뉴)를 눌렀을 때만 페이지를 확인합니다.

## 제3자

오디오를 변환할 때는 사용자가 고른 서비스가 데이터를 처리하며, 해당 데이터의 처리는 각 서비스의 정책을 따릅니다.

- Groq: https://groq.com/privacy-policy/
- OpenAI: https://openai.com/policies/privacy-policy/

영상 자체는 사용자의 브라우저와 영상을 제공하는 사이트(학교 LMS, 유튜브 등) 사이에서 내려받습니다.

## 권한과 필요한 이유

- **모든 사이트 접근**(`<all_urls>`): 강의 영상은 다양한 사이트와 CDN에서 제공되므로, 사용자가 쓰는 사이트에서 미디어 파일을 내려받고 선택한 페이지를 읽어야 합니다.
- **scripting / activeTab**: 영상 선택 화면을 띄우고, 선택한 탭에서 영상 원본을 찾기 위해 필요합니다.
- **offscreen**: 오디오를 내려받아 디코딩하고 변환하는 작업을 백그라운드 문서에서 실행하기 위해 필요합니다.
- **storage**: 설정, API 키, 스크립트를 기기에 저장하기 위해 필요합니다.
- **downloads**: 내보낸 스크립트 파일을 저장하기 위해 필요합니다.
- **declarativeNetRequestWithHostAccess**: 일부 CDN이 요구하는 강의 페이지의 `Referer`를 확장 프로그램의 다운로드 요청에 붙이기 위해 필요합니다.
- **contextMenus**: 우클릭 "이 페이지 영상 스크립트 만들기" 메뉴를 위해 필요합니다.

## 보관과 삭제

데이터는 사용자가 지울 때까지 기기에만 남습니다. 팝업에서 강의를 삭제하면 해당 스크립트가 지워지고, 확장 프로그램을 제거하거나 Chrome에서 확장 프로그램 데이터를 지우면 모두 삭제됩니다. 개발자 쪽에는 사본이 없으므로 삭제할 데이터가 없습니다. 이미 Groq이나 OpenAI로 전송된 데이터는 각 서비스의 보관 정책을 따릅니다.

## 아동

이 확장 프로그램은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 데이터를 알면서 수집하지 않습니다.
